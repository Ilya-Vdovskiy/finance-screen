# Лабораторная работа № 3 — экран личных финансов

Android-приложение на Kotlin и Jetpack Compose по варианту «Экран личных финансов». Данные демонстрационные: сеть, база данных и реальные банковские операции не используются. Визуальное направление вдохновлено Т-Банком: жёлтый акцент, крупные суммы, спокойные поверхности и скруглённые карточки.

## Что реализовано

- Обзор: общий баланс, два счёта, распределение расходов, последние операции.
- Экран деталей операции и возврат системной кнопкой «Назад».
- Три состояния обзора: наполнено, загрузка со скелетоном, пусто с действием.
- Светлая и тёмная тема, системный режим и ручной выбор с сохранением между запусками.
- Две колонки для Medium/Expanded `WindowSizeClass`.
- Плавные переходы между состояниями и экранами, превью обеих тем.

Нажмите на жёлтый круг с буквой «И» вверху обзора, чтобы открыть выбор темы и состояний. Нажмите на строку операции, чтобы открыть детали. В пустом состоянии кнопка «Показать финансы» возвращает демонстрационные данные.

## Запуск

Откройте корень проекта в Android Studio и запустите конфигурацию `app` на Android 7.0+ (API 24+). Для сборки из терминала: `gradlew.bat :app:assembleDebug`. Проект использует `compileSdk 35`, Kotlin 2.0.21 и Compose BOM. Для первой сборки нужен доступ к репозиториям Google и Maven Central.
